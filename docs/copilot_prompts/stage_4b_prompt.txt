   - `struct RunKey { std::uint64_t layoutSeed = 0; int runSeed = 0; };`
   - `int commonModeCount(int count)`: round-half-up of count / 5, computed as (2 * count + 5) / 10 in integer arithmetic.
   - `std::uint64_t runStreamSeed(std::uint64_t masterSeed, std::uint64_t layoutSeed, int runSeed)`: (masterSeed << 40) + (layoutSeed << 8) + runSeed, in std::uint64_t.
   - `std::vector<std::vector<FaultEvent>> generateFaultEvents(const std::vector<RunKey>& runs, const std::vector<WorldState>& layouts, std::uint64_t masterSeed)`. layouts[r] is the TRUE layout of runs[r] (same length; if the lengths differ, return an empty list). The result has one vector of exactly 3 events per run, in run order.
   - Experiment-level draws, with SeededRandom experimentRandom(masterSeed), in EXACTLY this order:
       a) n = 3 * runs.size(). types[i] = F(i mod 5 + 1) for i = 0..n-1 (F1, F2, F3, F4, F5, F1, ...). experimentRandom.shuffle(types).
       b) For each type in the order F1, F2, F3, F4, F5:
          - idx = the event numbers i with that type, ascending; perm = a copy of idx; experimentRandom.shuffle(perm).
          - k = commonModeCount(idx.size()). The first k events of perm are common-mode (target Both).
          - The remaining events of perm, in perm order, get R1, R2, R1, R2, ... (the first gets R1).
          - Only for F1, immediately after that: perm2 = another copy of idx; experimentRandom.shuffle(perm2); its events, in perm2 order, get FreeToBlocked, BlockedToFree, FreeToBlocked, ... (the first gets FreeToBlocked).
       Event number i belongs to run r = i / 3, as its event j = i mod 3 + 1.
   - Per-run draws, for each run r in order, with SeededRandom runRandom(runStreamSeed(masterSeed, layoutSeed, runSeed)):
       a) steps = runRandom.pickDistinct({1, 2, ..., 10}, 3), then sorted ascending. Event j gets steps[j-1].
       b) Then for j = 1, 2, 3 in order, the details of that event (layout = layouts[r]):
          - F1: candidates = interior cells (y from 1 to 8 outer, x from 1 to 8 inner), other than the destination, whose TRUE wall status is free (FreeToBlocked) or blocked (BlockedToFree). If any: hasCell = true, cell = candidates[runRandom.below(size)]. If none: hasCell = false and NO number is drawn.
          - F2: order = {North, East, South, West}; runRandom.shuffle(order).
          - F3: action = {North, East, South, West}[runRandom.below(4)], THEN rotation = {Left, Right}[runRandom.below(2)].
          - F4: candidates = interior cells (same order), other than the destination, that are dead in computeDeadSquares(layout, {}, {}, counts) (a local FreeComputationCounts). If any: hasCell = true, cell = candidates[runRandom.below(size)]; if none: hasCell = false, no draw.
          - F5: nothing is drawn.
   - `std::string faultEventText(const FaultEvent&)`, exactly this format (it is what the tests compare):
         <id> step <step> <F1..F5> target <R1|R2|both> | <details>
     details: F1 "(x, y) free->blocked" or "(x, y) blocked->free" ("none free->blocked" if no cell); F2 the four directions separated by single spaces; F3 "<Action> left" or "<Action> right"; F4 "(x, y)" ("none" if no cell); F5 "-".
