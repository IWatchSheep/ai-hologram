   - enum class InvestigationOutcome { BeliefCandidatesConsistent, NoCandidatePassed, ModelSuspected, Deferred };
   - struct InvestigationResult { InvestigationOutcome outcome; std::vector<BeliefCandidate> candidates; SourceLabel suspected; bool anomaly; };
   - InvestigationResult investigateMismatch(const WorldState& beliefBefore, Action action, const std::vector<Observation>& history, StepPredictor& predictor, const ActionModel& currentModel, int reserve);
     - history's last two entries are o_t-1 (before the action) and o_t (after it).
     - Exactly plan 3.7 A:
       - Anomaly when the believed agent differs from o_t-1's agent.
       - Belief candidates from the footprint (computed from beliefBefore, the action and o_t):
         - walls: each footprint cell whose believed wall differs from o_t-1;
         - object: when the believed or recorded object is in a footprint cell and they differ; its value is o_t-1's object position, which may lie outside the footprint.
       - Candidates are verified TOGETHER:
         - every history check (3.8 V1 table) must pass;
         - plus ONE variant re-prediction with the CURRENT model, from beliefBefore with all candidates applied, compared on the footprint computed from that corrected belief with o_t.
         - The re-prediction is optional: if predictor.remaining() <= reserve, return Deferred without predicting.
       - Suspected source:
         - S2 when candidates exist;
         - S1 and ModelSuspected when none exist;
         - S5 for NoCandidatePassed.
   - enum class ConsequenceOutcome { NotApplicable, FullStateDeadEnd, Mismatch };

4. src/agent/verification.h / .cpp (plan 3.8):
   - bool wallHistoryCheck(Position cell, bool blocked, const std::vector<Observation>& history): checks EVERY recorded observation (walls never change).
   - bool objectHistoryCheck(Position value, const Observation& before): compares ONLY with o_t-1. Time-aware: earlier positions are never compared, because the object moves.
   - Model V1:
     - struct ModelV1Work { Action action; std::vector<int> pendingIndices; };
     - ModelV1Work startModelV1(Action, history): indices k whose lastAction is the action, in history order;
     - enum class V1Progress { Done, Pending, Failed };
     - V1Progress continueModelV1(ModelV1Work&, history, StepPredictor&, int reserve):
       - each replay is predictor.predictVariant(history[k-1].state, action, applyAction), i.e. the STANDARD rule;
       - each replay must equal history[k].state and history[k].lastOutcome;
       - it stops (Pending) before a replay if remaining() <= reserve.
   - bool trapV1Check(belief, map, Position p, history, counts): the local check FAILS at p, and the history check of plan 3.7 B.3 passes.
   - Trap V2:
     - enum class TrapV2Result { Verified, Rejected, Waiting };
     - TrapV2Result trapV2Test(belief, map, Position p, StepPredictor&, const ActionModel& currentModel, int reserve, int& anomalies), exactly plan 3.8:
       - for each direction N, E, S, W with p-d believed free, build the hypothetical state (belief walls and destination, agent at p-d, object at p);
       - skip it, and add 1 to anomalies, if it is not a valid world;
       - predict the push with the CURRENT model, as a variant;
       - Waiting if remaining() - k < reserve (k = number of valid hypotheticals), making no prediction at all;
       - Rejected if any predicted push moves the object onto a cell that is not dead; else Verified.
   - std::optional<Prediction> alternativePrediction(const CorrectionRecord&, const WorldState& belief, Action action, StepPredictor&, const ActionModel& currentModel, const ActionModel& oldModel):
     - the relevance rules of plan 3.8 (wall cell c: c is c1 or c2; object: the old or current believed position is c1 or c2; model(b): b is the action);
     - returns std::nullopt WITHOUT any evaluation when not relevant, or when the alternative belief is not a valid world;
     - wall and object alternatives use the CURRENT model on the belief with the element set to its OLD value;
     - model alternatives use the OLD model.
   - bool predictionsDiffer(const Prediction&, const Prediction&): outcome, agent position or object position.
   - std::vector<std::pair<Position, Action>> activeTestTargets(const WorldState& belief, Position cell): the cells n = cell - d (directions N, E, S, W) that are believed free and not the believed object cell, each with the move d into the cell.
