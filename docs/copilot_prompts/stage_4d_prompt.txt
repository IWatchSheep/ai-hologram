   THE ALGORITHM (exactly; it is what the reference does). Element of an event: F1 -> Wall(cell); F2, F5 -> Object; F3 -> ActionModel(action); F4 -> Trap(cell). Element of a correction record: its `element` (kind, and cell for Wall/Trap, action for ActionModel; Object has no cell). Ground-truth source: S2 for F1, F2, F5; S1 for F3, F4.
   "Active now" for an activated event, from the view and the true world:
       F1: isWall(*belief, c) != isWall(trueLayout, c);
       F2, F5: belief->object != trueHistory->back().state.object;
       F3: !model->isRestored(action);
       F4: c is not in *deadOverrides.
   endPhaseA(view, t) sets the current step to t, then runs endPhase(view). endFinalCheck(view) runs endPhase(view) with the current step unchanged (D-045).
   endPhase(view):
       a) startActive[i] = activated && endState == None && active  (for every event, before anything below).
       b) New claims: every correction record not yet seen (in id order). For each: claims++; if !claimValueIsTrue(...) then wrongAccepted++. Find the events whose element equals the record's element AND startActive; if there are none, falseAlarms++; for each such event without a strictStep, strictStep = current step. Remember which records are new in this phase.
       c) New mismatch records (every record not yet seen): mismatches++; causes = the remembered committed causes (from the last afterDecide) that are startActive. If causes is empty: mismatchesWithoutCause++. Otherwise labelsScored++, and labelsCorrect++ if the record's `suspected` equals the ground-truth source of at least one cause; each cause without a mismatchStep gets mismatchStep = the record's decisionStep.
       d) Event life, for every activated event, with now = "active now":
          - if endState == None and active and !now:
              * if a NEW record (this phase) has the event's element and a true value: Corrected, correctingId = the LAST such record's id, endStep = current step;
              * else if the event is F3 or F4: Corrected, correctingId = the last record in the whole list with the event's element whose status is not Rejected (0 if none), endStep = current step;
              * else: Overwritten, endStep = current step;
              * active = false.
          - else if endState == Corrected and correctingId != 0 and that record's status is now Rejected and now is true: endState = None, active = true, correctingId = 0, endStep = 0 (the same event is active again; plan 3.7).
       e) The remembered committed causes are cleared.
   afterActivation(view, records, t): for each event i whose records[i].status is Applied and which is not yet activated: activated = true, activationStep = t, active = true; if it is not "active now" (for example F2 moved the believed object onto the true one), then active = false, endState = Overwritten, endStep = t.
   afterDecide(view, decision): first endPhase(view) (phase B). Then:
       - if !decision.isAction: if any event is activated && endState == None && active, justifiedSafeStops++. Return.
       - if view.committed is not null and committed->has: pre = committed->beliefBefore, a = committed->prediction.action, the result = (committed->prediction.state, committed->prediction.outcome). For every event that is activated && endState == None && active, if committedEffective(event, pre, a, result, view) then: remember it as a committed cause; revealing = true; if no opportunityStep, opportunityStep = current step.
   committedEffective (the shadow of the committed prediction, plan 3.9; the scorer calls the model function itself, so no budget is used):
       - F4: false.
       - F3: true only if a == the event's action and !model->isRestored(a), and the result differs from applyAction(pre, a).
       - F1: shadow = pre with cell c set to its TRUE wall status; if pre already has the true status, false.
       - F2, F5: let b = *view.belief and T = trueHistory->back().state.object; if b.object == T or pre.object != b.object, false; otherwise shadow = pre with object = T.
       - For F1, F2, F5: if !isValidWorld(shadow), true. Otherwise shadowResult = view.model->current()(shadow, a), and the use is effective if the two predictions differ: their outcomes differ, or compareFootprint finds a difference on the cells of computeFootprintForTwoPredictions(pre, result outcome, shadow, shadow outcome, a), comparing the result state with the shadow state.
   finish(view): for every event with endState == Corrected and correctingId != 0, correctionStatus = that record's status (if the view has corrections).
   For C0 the view has no corrections, mismatches or committed prediction: those steps simply do nothing.
   Beginner comments: the referee never touches the dog (reads only); why there are two phases (D-037); credit only through records; why an object claim is judged at the moment it is about (D-042, the "stale address" in the owner's words); what a revealing opportunity is; why a mismatch with no fault cause is counted and reported as a possible bug, never assumed impossible.
