1. src/agent/step_predictor.h / .cpp - class StepPredictor (plan 3.4, 4.2).
   Construction:
   - It is constructed with a WorldModel and a per-step budget B.
   Public members:
   - void startStep(): a new BudgetCounter with limit B (unused budget is lost), and the cache is cleared.
   - std::optional<Prediction> predict(const WorldState& state, Action action): looks in the cache first; a hit is free. A miss calls WorldModel::predict through the step's BudgetCounter (exactly one evaluation) and stores the result.
   - The cache key is (agent position, object position, action). The predictor remembers the walls and destination its cached entries belong to; a predict() call with different walls or destination clears the cache before looking.
   - bool isCached(const WorldState& state, Action action) const.
   - std::optional<Prediction> predictVariant(const WorldState& state, Action action, const ActionModel& model): never reads or fills the cache; it always costs exactly one evaluation from the same BudgetCounter, using a WorldModel built from the given model.
   - void clearCache(): for when the model or the trap overrides change.
   - int remaining() const; int usedThisStep() const; int usedTotal() const.
   Rules:
   - When the budget is exhausted, every prediction returns std::nullopt and changes nothing.
   - Never create a successor state in any other way.

2. src/agent/planner.h / .cpp - the A* of plan 3.5, exactly.
   Types:
   - struct PlanStep { Action action; WorldState expected; };
   - enum class SearchKind { Found, OutOfBudget, Exhausted };
   - struct DiscoveredState { WorldState state; int bestG; int h; int parentIndex (-1 for the root); Action action; int discoveryNumber; };
   - struct SearchResult { SearchKind kind; std::vector<PlanStep> plan; std::vector<DiscoveredState> discovered; int improvedPaths = 0; int reopenedStates = 0; }.
     - improvedPaths counts how many times an already-discovered state's bestG was replaced by a shorter path.
     - reopenedStates counts how many of those replacements reopened a closed state.
   Functions:
   - SearchResult search(const WorldState& root, const DeadSquareMap& map, const std::function<bool(const WorldState&)>& goalTest, const std::function<int(const WorldState&)>& heuristic, StepPredictor& predictor, int reserve);
   - std::vector<PlanStep> fallback(const SearchResult& result): the discovered NON-ROOT state with the smallest (h, bestG, discoveryNumber) whose h < kInfiniteHeuristic. An empty vector means no action.
   Algorithm (plan 3.5):
   - The queue entries are (f = g + h, h, entry number, state index), smallest first; entry numbers increase by one each time an entry is added.
   - Outdated entries are skipped: g is not the state's bestG, or the state is already closed.
   - The goal is tested when an entry is TAKEN from the queue (the root is taken first, so an already-solved root gives Found with an empty plan and 0 evaluations).
   - Expansion order is North, East, South, West.
   - Before each prediction that is not cached: if predictor.remaining() <= reserve, return OutOfBudget.
   - Skip a result that is Blocked or InvalidState, or whose object is on a dead square (map), or whose g' >= the known bestG.
   - Otherwise discover the state, or improve it (reopening it if it was closed), and add a new entry.
   - If the queue empties, return Exhausted.
   - Use std::priority_queue with a clear comparator, or another standard container, and explain the ordering in beginner comments.
