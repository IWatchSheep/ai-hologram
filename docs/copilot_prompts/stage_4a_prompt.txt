     All arithmetic is std::uint64_t (it wraps modulo 2^64 by definition; add a comment saying so).

   - Returns 0 if the object is already on the destination.
   - Otherwise a breadth-first search over (agent position, object position) using the Stage 1 rules (the same function the Environment uses to apply an action), trying North, East, South, West in that order, skipping Blocked results and states already seen.
