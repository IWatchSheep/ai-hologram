EXACT ORDER OF A DECISION STEP (plan 3.6). It must be followed exactly, because the evaluation counts in the expected output depend on it.

decide(observation):
 1. decisionStep += 1; predictor.startStep() (new budget B, cache cleared); append the observation to the history (the first observation is history[0] from construction, so it is not appended again on decision step 1).
 2. CHECK the committed prediction, if any (it exists only after a world action):
    a. compute the footprint from the belief BEFORE that action, the action, and the observation; compare;
    b. log the step line for the decision step that committed it;
    c. for each correction this prediction was testing, if still CONSISTENT: on a match, VERIFIED (log "correction N: VERIFIED"); on a mismatch, REJECTED (log "correction N: REJECTED") and revert it (plan 3.8: a wall gets its old value back; a model loses its restoration; a trap loses its override; an object record is only marked);
    d. on a match: applyFootprintUpdate;
    e. on a mismatch: mismatches += 1, then investigate (plan 3.7 A) with investigateMismatch, using the belief before the action, the history, the CURRENT model and the current reserve:
       - first log one investigation line per candidate (or the model-suspicion line), in candidate order (wall cells in footprint order, then the object);
       - BeliefCandidatesConsistent: apply each candidate as its own CONSISTENT correction, in candidate order, logging "correction N: ... CONSISTENT" (stepConsistent = the current decision step); then applyFootprintUpdate with the observation;
       - NoCandidatePassed: log the unexplained-update line; applyFootprintUpdate;
       - ModelSuspected: applyFootprintUpdate NOW (provisional, D-025); startModelV1 for the action; then continue it at once (step 4 below);
       - Deferred: log "investigation: budget too small for verification; retried next step"; keep it as a deferred investigation; do not update the belief.
 3. If an investigation is deferred: retry it now with this step's budget, WITHOUT logging its investigation lines again. If it is still deferred, safe-stop with reason "budget too small for verification" and return.
 4. If a trap V2 test is waiting: try trapV2Test again (Verified: log "correction N: VERIFIED"; Rejected: log REJECTED and revert; Waiting: keep waiting).
    If model V1 work is pending: continueModelV1 with the current reserve.
    - Done: restore the action in the AgentActionModel, clear the predictor cache, and create the CONSISTENT model correction (log its line).
    - Failed: log "investigation: no candidate passed V1 (source S5); unexplained update" and drop the work.
 5. (Fault activation point: a separate, commented, EMPTY step.)
 6. CHOOSE:
    a. If model V1 work is still pending: cautious mode (plan 3.9).
       - For N, E, S, W: stop checking if remaining() - need < reserve, where need = 1 (the standard-rule variant) + 1 if the current-model prediction is not cached.
       - Predict with the current model (cached) and the standard rule (variant). The first action whose two predictions agree in outcome, agent and object, and whose result is not on a believed dead square, is chosen: log "Plan: cautious mode (investigation unfinished)", make it the plan, and go to COMMIT.
       - If none: safe-stop "investigation unfinished, no cautious action".
       - NOTE (expected, by the plan's budget order 3.4/protocol 11.7): V1 replays use the budget down to the reserve first, so while V1 work is still pending at this point, cautious checks normally cannot be afforded and C1 safe-stops. That is correct behaviour, not a bug; report it in your handoff note.
    b. reserve = 1 + number of CONSISTENT corrections whose element is a wall, the object or an action model (recomputed whenever a status changes).
    c. ACTIVE TEST (plan 3.8):
       - Applies only if the current plan is not already a test plan.
       - For each wall correction in correction order that is CONSISTENT with decisionStep - stepConsistent >= activeTestDelay: targets = activeTestTargets(belief, cell); if there are any, search with goal "agent is on a target cell" and heuristic "smallest manhattan distance to a target, or kInfiniteHeuristic if the object is on a dead square", using the reserve.
       - If Found: the test action is the target's move from the walk's end state (the root if the walk is empty). Its prediction (from that end state) is made only if cached or if remaining() > reserve.
       - If all succeeds: plan = walk + test step; plan kind = test; log "Plan: active test of correction N (K actions)"; stop looking. Otherwise there is no test this step.
    d. KEEP THE PLAN? If the plan is not empty:
       - predict its first action from the current belief (normally cached);
       - if no prediction: clear the plan and safe-stop "no budget for a committed prediction";
       - if the predicted state equals the expected state (walls, agent, object, destination) and its object is not on a believed dead square: go to COMMIT with it;
       - otherwise clear the plan.
    e. MAIN SEARCH: search(belief, map, object-on-destination, heuristic of 3.3, predictor, reserve).
       - Found with an empty plan: safe-stop "belief shows goal reached".
       - Found: the plan; log "Plan: search found a plan of K actions".
       - Exhausted: first checkConsequence; on FullStateDeadEnd log the surprise line then the full-state dead end line; on Mismatch log the surprise line, the consequence mismatch line, create the trap correction (log its CONSISTENT line, add the "dead" override), then run trapV2Test at once (log VERIFIED/REJECTED, or keep it waiting). Then use the fallback.
       - OutOfBudget: use the fallback.
       - Fallback: if empty, safe-stop "budget too small to plan" (after OutOfBudget) or "no safe action" (after Exhausted); else make it the plan and log "Plan: fallback toward the best state found (K actions)".
    f. Predict the plan's first action from the current belief (cached when possible). If no prediction: clear the plan and safe-stop "no budget for a committed prediction".
 7. COMMIT:
    - Remove the first plan step; if the plan is now empty, the plan kind becomes none.
    - V2 BOOKKEEPING: for each correction in correction order that is CONSISTENT and not yet tested, call alternativePrediction (current model; old model = the AgentActionModel's base for model corrections). If it returns a prediction and predictionsDiffer from the committed one, this step tests that correction: mark it tested.
    - Remember the committed prediction, a copy of the current belief (the belief BEFORE the action), the decision step and the tested corrections.
    - Return the action.
 SAFE STOP: safe stops += 1; log "Step t: safe stop (reason)" with t = this decision step; return a stop. No committed prediction.

finalCheck(observation): predictor.startStep(); append to history; CHECK (step 2 only).

Applying corrections:
- wall: set the belief wall (the dead-square cache reruns because the walls changed; the predictor's cache clears itself on the next predict with new walls);
- object: set the believed object;
- model: restore + clearCache;
- trap: add to the "dead" list, so the cache reruns.
Old values come from the belief BEFORE the action.

RUN LOOP (plan 3.10):
- If the true initial object is already on the destination: Success, 0 world steps, no decision.
- Otherwise the first Observation is the true state at decision step 1. Loop:
  - decide;
  - after an action: Environment::step; next observation = new state, the action, the outcome, decisionStep = agent's decision step + 1; if the object is on the destination: finalCheck, Success; else if world steps == maxWorldSteps: finalCheck, Step limit;
  - after a safe stop: if the safe-stop count == safeStopLimit: Stopped -- unresolved; else the next observation repeats the state with no action and no outcome.
